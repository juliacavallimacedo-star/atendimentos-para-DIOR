# atendimentos-para-DIOR

OBJETIVO
- saber o nome do vendedor.
- sabero o nome do cliente.
- descobrir o valor dos descontos. Quanto sera pago com o desconto.
- descobrir o valor da compra.

INFORMAÇõES
- valores ACIMA de R$: 300,00 tem o desconto de 15%.
- valores ENTRE R$: 300,00 e R$: 150,00 tem o desconto de 10%.
- valores ABAIXO de R$: 150,00 nao tem desconto.
